# App Icon

Drop a **1024x1024 `icon.png`** in this folder and re-run `npm run release:mac`
(or `./scripts/build-mac.sh`) — it will automatically generate `icon.icns`
from it via macOS's built-in `sips`/`iconutil` tools.

If no icon is provided, the release build falls back to Electron's default
icon (the app still builds and runs fine, it just won't be branded).

Files in this folder:
- `icon.png`  — source image you provide (1024x1024, transparent background recommended)
- `icon.icns` — auto-generated by the release script, don't edit by hand
